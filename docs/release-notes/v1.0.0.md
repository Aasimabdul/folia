## Folia v1.0.0 — first stable release

A free, offline, open-source document reader for Android. No ads, no tracking, no internet permission.

### Highlights
- **PDF pages keep their original colours in dark mode** (new default). Choose *Original colours*, *Match app theme*, *Always dark pages*
  or *Sepia* in **Settings > Document pages**, or tap the colour dot in the reader. A switch softens bright white pages at night.
- **Full-screen reading** with hidden status and navigation bars (swipe from an edge to peek).
- **Page thumbnails at the bottom** of the reader, tap to jump. The old bottom slider is gone.
- **Library file manager**: add folders with the system picker, browse sub-folders, search, sort (name, date, size, type), list/grid view,
  rename, share and delete.
- **Sketch / Annotate** on PDFs and images: pen, highlighter, eraser, colours, thickness, undo/redo. Sketches autosave and come back when you
  reopen the file; the original is never modified. **Save annotated copy** writes a new PDF to a folder you choose.
- **Text editor** for TXT, Markdown, code and other plain-text files, with unsaved-changes protection, overwrite confirmation and Save as.

### Security and privacy
- Zip-bomb limits, embedded-image budget, XML parsing without DOCTYPE or external entities, 512 MB open limit, cleartext traffic disabled.
- Still **no INTERNET permission**; temporary copies are deleted when the app closes.
- New project files: `SECURITY.md`, `PRIVACY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `THIRD_PARTY_NOTICES.md`, `CHANGELOG.md`.

### Installing and updating
- Updating from **0.3.3**: installs over the old version, no uninstall needed.
- Updating from **0.3.2 or older**: uninstall once first (those builds were signed with a different key).
- Choose the APK for your phone: **arm64-v8a** for almost all modern phones, **armeabi-v7a** for old 32-bit devices.
- Verify the download: `sha256sum -c SHA256SUMS.txt`.

### Good to know
- Editing works for plain-text formats. DOCX, PDF, EPUB and other formats are read-only; the app says so.
- Sketching is available for fixed-layout pages (PDF, images). Reflowable text (EPUB, Word, ...) changes layout, so strokes could not stay in place.
- An annotated copy is a PDF whose pages are pictures (text is not selectable in the copy).
- The Library only shows folders you grant, as Android's scoped storage requires.
- Release APKs are signed with the public sideload key in `signing/` (consistent updates, not publisher identity). See `SECURITY.md`.

### Build verification
Unit tests, debug and release builds, and APK signature checks pass in CI before this release is published.
Behaviour on real devices (stylus drawing, full-screen on different phones, SAF providers) has not been tested by the maintainers' automation.
