# Privacy

**Folia collects nothing.** There is no account, no server and no tracking.

| Question | Answer |
|---|---|
| Does Folia use the internet? | No. The app has no `INTERNET` permission. |
| Does it send my documents anywhere? | No. Everything is processed on your device. |
| Analytics, ads, crash reporting? | None. |
| What does it store? | Recent-file list and reading progress, your settings, the folders you added to the Library (as Android access tokens), and your sketches. All in the app's private storage. |
| Temporary copies | The open document is copied to the app cache while you read it and removed when the app closes. |
| Which permissions does it use? | None at install time. Files are opened through the system file picker, "Open with", or folders you choose. |
| How do I remove my data? | Android Settings > Apps > Folia > Storage > Clear data (or uninstall). Removing a folder in the Library also revokes Folia's access to it. |

Sketches are stored separately from your documents and never change the original file. If you save an annotated copy or save edited
text, the file is written only to the location you choose in the system file picker.
